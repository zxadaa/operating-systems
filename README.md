# Operating Systems Course 

This repository contains C exercises completed for an Operating Systems course. The programs demonstrate process creation, signals, inter-process communication, shared memory, synchronization, POSIX threads, scheduling, and network sockets.


## Contents

| Lab | Main topics |
| --- | --- |
| `lab1` | Process creation with `vfork`, `fork`, `exec`, and `wait` |
| `lab2` | Signal dispositions, signal masks, handlers, and static/shared/dynamic libraries |
| `lab3` | Anonymous pipes, parallel numerical integration, and named pipes (FIFOs) |
| `lab4` | A multi-client chat using System V message queues |
| `lab5` | Producer-consumer synchronization using POSIX shared memory and named semaphores |
| `lab6` | Multithreaded sensor pipeline, circular buffers, atomics, and real-time scheduling |
| `lab7` | TCP client-server communication with IPv4 sockets |


## Requirements

-  linux operating system recommended
- `gcc`
- `make` for the exercises that include a Makefile
